How does it works?

It uses the dictionary feature of the phyton. It is similar to google translate: you choose two languages at there and when you type a word on the left side, its translation appears on the right side.

So in this code there is  two languages "Prompt/Answer" when you enter a prompt and define its answer, every time you type that prompt , the bot will print in the "Answer" language. 

As you can see at the  left side there is the prompt and at the other side there is the answer of the prompt (prompt/answer) so it literally equalize the prompt to the answer.  

And every time you type a prompt that is not saved in dictionaary, AI asks "Teach me how to asnwer=" and the text that you are typing there is the new answer to that prompt it is easy.

AND ALL CODE IS JUST IN 23 LINES LONG

Because there is no data base it forgets every thing when you restart or terminate the code.
